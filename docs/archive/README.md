# Archive

**Do not read anything in here unless a task names a specific file.**

This is the reasoning behind Fathom, written mostly between June and September 2026 — most of it
about a version of the product that no longer exists. It was archived on 2026-09-11 when the
client rebuild began.

It is kept because the thinking is good and was expensive to produce. It is archived because
reading it by default was the single largest running cost in the project.

Current truth lives in `docs/STATE.md`. The plan lives in `docs/REBUILD-PLAN.md`. Decisions that
still bind live in `docs/decisions/`.

If you find yourself reading in here to answer a general question, stop — the answer you need is
probably in one of those three.
