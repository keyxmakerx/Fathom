Lines 34–36 · will not do what it looks like
This permits the whole internet into your trusted network.
The policy is named allow-web, which reads as though it permits web traffic. It does not mention a port, a protocol or an application anywhere, so the device will not restrict it to web traffic — it matches any source, any destination, and permits.
What the device will actually do: permit every packet arriving on untrust to reach anything in trust, for any port.
A policy name is a label. The device does not read it.
Fathom is not telling you this is wrong — you may have meant it. It is telling you the name and the behaviour disagree.
Also worth a look
41
This OSPF password is stored in a form the device can reverse.
Junos $9$ encoding is obfuscation, not encryption — anyone with the config can recover the password. Fathom destroyed this value when you pasted it and did not store it.
44
This relay points at a server Fathom cannot find.
DHCP relay sends requests to 10.10.0.9, which is not a device in this design. Either it lives outside what you have drawn, or the address is wrong.
49
The SNMP community is the default one.
Read-only, but public is the value every scanner tries first. Anyone who can reach this device can read its configuration state.
Fathom explains what a configuration does. It does not decide whether that is right for your network.
