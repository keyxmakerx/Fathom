why can't the sales laptops reach the file server?
Answer
Sales is on 10.10.20.0/24 (VLAN 20, line 29) and the file server is on 10.10.30.0/24 (VLAN 30). Both interfaces are in the same zone, trust (line 31).
There is no policy set for trust → trust in this config. On this platform, traffic between two interfaces in the same zone is governed by intra-zone policy, and none is written here.
That is what the configuration says. Whether the device's default for intra-zone traffic on your Junos version permits or denies it is a platform behaviour I will not assert — check the release notes for the version this box runs, which is not in the pasted text either.
